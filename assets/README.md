# App Assets

Static images Expo bundles at build time, referenced by `app.json` (not imported from app code):

- `icon.png` — app icon (iOS light appearance, Android, web)
- `icon-dark.png` — iOS dark appearance app icon
- `icon-tinted.png` — iOS tinted appearance app icon (grayscale; the system applies the tint)
- `splash-icon.png` — launch screen icon (transparent, drawn on the dark splash background)
- `android-icon-foreground.png` — Android adaptive icon foreground layer
- `android-icon-background.png` — Android adaptive icon background layer
- `android-icon-monochrome.png` — Android adaptive icon monochrome (themed) layer
- `favicon.png` — web favicon
